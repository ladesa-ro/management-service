# Security Policy

Encontrou uma vulnerabilidade de segurança? Não abra uma issue pública. Envie um e-mail de forma privada pra:

```
ladesa.sisgea@gmail.com
```

Confirmação de recebimento em até 48 horas, avaliação inicial em até 5 dias úteis. Só a última versão publicada, ou o branch `main`, recebe correção de segurança.

Política completa (o que incluir no reporte, classificação de severidade, escopo, divulgação responsável): [docs/operacao/seguranca.md](docs/operacao/seguranca.md).
